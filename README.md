## 🛠️ How It Works (Simple Explanation)

Your Obsidian notes are stored as plain text files on your computer. Inside those files, there are special links that connect one note to another. vault-graph reads those links and draws them as a network of dots and lines. It's like a map of your brain – every note is a city, and every link is a road between cities.

The magic is that this all happens inside a single HTML file. That means the program itself is just a web page that runs in your browser. It reads your files, processes the connections, and draws the graph – all without needing any other software.

## 📁 Finding Your Vault

When you first open vault-graph, it might ask you to choose your Obsidian vault folder. Here's how to find it:

1. Open Obsidian on your computer.
2. Look at the bottom left corner of Obsidian. You'll see your vault name.
3. Click on the vault name, then select "Open folder" from the menu that appears.
4. Your File Explorer will open showing your vault's contents. The address bar at the top shows the full path (like `C:\Users\YourName\Documents\MyVault`).
5. In vault-graph, navigate to that same folder and select it.

If vault-graph doesn't ask for a folder, it might use the default location where Obsidian stores vaults. You can usually find these in your Documents folder.

## 🔧 Troubleshooting

**The graph is empty or shows no connections**
- Make sure you've selected the correct vault folder. Double-check that you're pointing to the folder that contains your `.md` files.
- Check that your notes actually have links in them. Open a note in Obsidian and look for `[[Note Name]]` text. That's what creates connections.

**The file won't open**
- Right-click the file and select "Open with," then choose your web browser (Chrome, Edge, or Firefox).
- Make sure you've fully downloaded the file. Sometimes browsers pause downloads. Check that the file size matches what was shown on the download page.

**The graph is slow**
- If you have thousands of notes, the graph might take a moment to load. Give it a few seconds.
- Close other browser tabs to free up memory.

**I see a blank white screen**
- Try refreshing the page (press F5 or Ctrl+R).
- If that doesn't work, close the browser tab and reopen the file.
